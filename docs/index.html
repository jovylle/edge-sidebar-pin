edge-sidebar-pin

Pin Messenger, WhatsApp, or any site in the Edge sidebar by repointing a slot you already have — after Edge retired “Add app”.

View on GitHub Download ZIP

Demo

Quick start

  1. Clone or download the repo (Windows 10/11 + Edge required).
  2. You need at least one existing sidebar app (Copilot, Twitch, ChatGPT, …).
  3. Double-click Start.cmd — pick a slot, pick a site, confirm. Edge closes only when you confirm.
  4. Open Edge normally. Undo with Restore.cmd if needed.

Presets

Messenger WhatsApp Telegram Discord Instagram Spotify Slack Teams

Custom URLs work too: Pin.cmd "https://yoursite.com/" "Label". Something wrong? Try Start-FullLog.cmd for a saved debug log.
